Why CloudVault

Everything you need for
cloud file storage

Built on battle-tested AWS infrastructure. Enterprise reliability without enterprise complexity.

🚀

Zero Disk Usage

Files stream directly from your browser to S3 via multer-s3. No temporary copies ever touch the server filesystem.

🔗

Permanent Share Links

Generate a shareable link for any file. The link never expires — each visit gets a fresh 1-hour presigned S3 URL.

🛡

Fault Tolerant

Nginx load balances across two Node.js instances. If one fails 3 health checks, it's removed from the pool automatically.

🗄

DynamoDB Metadata

File IDs, S3 keys, names, MIME types, sizes and timestamps are stored in DynamoDB for instant lookups at any scale.

⚡

Presigned URLs

Downloads use time-limited presigned S3 URLs. Your AWS credentials never leave the server — ever.

🌐

Fully Responsive

Dashboard adapts to any screen size. Light and dark themes follow your OS preference with a manual override button.
