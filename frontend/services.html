FAQ

Frequently asked questions

Do I need my own AWS account?

Yes. CloudVault uses your own AWS credentials (S3 bucket + DynamoDB table) so you have full ownership and control of your data. We never store your credentials.

Can I share files with people outside my organisation?

Absolutely. Each file gets a permanent share link at /share/:fileId. Anyone with the link can download the file — no account needed.

How do presigned URLs work?

When someone visits a share link, our server generates a 1-hour time-limited S3 URL and redirects them to it. Your S3 credentials are never exposed to the downloader.

What happens if one server goes down?

Nginx polls each Node.js instance every 10 seconds. If a server fails 3 consecutive health checks, it's removed from the load-balancing pool automatically. Traffic continues to the remaining healthy server.
